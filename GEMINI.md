## Agent knowledge base

Follow `AGENTS.md`.

- Before writing a reusable script, read `INDEX.md` for the file path and description (or `rg -i "<keyword>" INDEX.md */INDEX.md`).
- Reuse a tool with `--help`. Do not read its source unless you are fixing or extending it.
- Create one folder per script and put the file inside it. On add, edit, or delete, update `INDEX.md` and that language `INDEX.md`.
